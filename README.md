# Lampa Weather Premium — Микитинці

Анимированный погодный виджет для **Lampa** на Samsung TV / Tizen. Показывает погоду рядом со стандартными часами (не скрывает время).

## Установка

В Lampa откройте **Настройки → Плагины → Добавить** и вставьте ссылку:

```
https://cdn.jsdelivr.net/gh/DoubleGGameRR/Lampa-Weather-Premium@main/public/weather-premium.js
```

Если установлен старый погодный плагин `https://lavliet2.github.io/Lampa/weather-plugin.js`, удалите его, чтобы на экране не было двух погодных виджетов. Перезапустите Lampa.

## Особенности

- По умолчанию: **Микитинці возле Ивано-Франковска** (фиксированные координаты, без IP и разрешения на геолокацию).
- В настройках можно выбрать одноимённое село Косовского района.
- Текущая температура, описание, погодная иконка, ощущаемая температура, влажность, максимум и минимум за день.
- Оформление **Glass** и **Minimal**, дневные и ночные цвета, плавные анимации SVG.
- Описания на русском и украинском.
- Бесплатный для некоммерческого использования API **Open-Meteo**, без API-ключа. Обновление раз в 20 минут, резервный кэш на три часа.
- Время в верхней панели Lampa остаётся видимым.

## Настройки

В Lampa: **Настройки → Интерфейс** (в некоторых сборках — подраздел стиля):

- Погода Premium — показывать
- Погода Premium — населённый пункт
- Погода Premium — оформление (Glass / Minimal)
- Погода Premium — детали
- Погода Premium — язык (Русский / Українська)

Плагин вставляется рядом с `.head__time` и рассчитан на совместимые сборки Lampa. Реальная работа на конкретном Samsung TV пока не проверена.

## Технические сведения

Файл плагина: `public/weather-premium.js`. Статическая загрузка через [jsDelivr](https://www.jsdelivr.com/) из открытого репозитория GitHub. Изменения на CDN могут появляться не сразу из-за кэширования.

Источник данных: [Open-Meteo](https://open-meteo.com/). API без ключа доступен при соблюдении условий сервиса (некоммерческое использование).
